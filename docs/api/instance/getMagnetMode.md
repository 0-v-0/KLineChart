# getMagnetMode()
`getMagnetMode` 获取十字光标的磁吸强度。

## 参考 {#reference}
<!--@include: @/@views/api/references/instance/getMagnetMode.md-->

### 参数 {#parameters}
`getMagnetMode` 不接受任何参数。

### 返回值 {#returns}
`getMagnetMode` 返回 `'normal'` 、 `'weak'` 或 `'strong'` 。
