# clearOverlaySelection()
`clearOverlaySelection` 取消全部覆盖物的选中状态。

<!--@include: @/@views/api/references/instance/clearOverlaySelection.md-->

### 参数 {#parameters}
`clearOverlaySelection` 不接受任何参数。

### 返回值 {#returns}
`clearOverlaySelection` 返回 `undefined` 。
