# setShowSelectedOverlayLabel(show)
`setShowSelectedOverlayLabel` 设置选中的覆盖物是否在坐标轴上显示标签，用于多选时只看要看的几个。

## 参考 {#reference}
<!--@include: @/@views/api/references/instance/setShowSelectedOverlayLabel.md-->

### 参数 {#parameters}
- `show` 是否只在选中的覆盖物上显示轴标签。

### 返回值 {#returns}
`setShowSelectedOverlayLabel` 返回 `undefined` 。
