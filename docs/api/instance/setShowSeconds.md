# setShowSeconds(show)
`setShowSeconds` 设置秒是否显示，开启后十字光标标签和时间轴标签的时间会带上秒。

## 参考 {#reference}
<!--@include: @/@views/api/references/instance/setShowSeconds.md-->

### 参数 {#parameters}
- `show` 是否显示秒。

### 返回值 {#returns}
`setShowSeconds` 返回 `undefined` 。
