# setShowSelectedOverlayLabel(show)
`setShowSelectedOverlayLabel` set whether axis labels are drawn only for the selected overlays, so a crowded chart can show just the ones that matter.

## Reference {#reference}
<!--@include: @/@views/api/references/instance/setShowSelectedOverlayLabel.md-->

### Parameters {#parameters}
- `show` Whether axis labels are limited to the selected overlays.

### Returns {#returns}
`setShowSelectedOverlayLabel` returns `undefined` .
