# setSelectedOverlayIds(ids)
`setSelectedOverlayIds` select overlays; an empty array clears the selection.

## Reference {#reference}
<!--@include: @/@views/api/references/instance/setSelectedOverlayIds.md-->

### Parameters {#parameters}
- `ids` The overlay ids. An id that matches no overlay is ignored.

### Returns {#returns}
`setSelectedOverlayIds` returns `undefined` .
