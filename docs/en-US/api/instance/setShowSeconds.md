# setShowSeconds(show)
`setShowSeconds` set whether seconds are shown; with it on, the crosshair label and the time axis labels carry seconds.

## Reference {#reference}
<!--@include: @/@views/api/references/instance/setShowSeconds.md-->

### Parameters {#parameters}
- `show` Whether seconds are shown.

### Returns {#returns}
`setShowSeconds` returns `undefined` .
