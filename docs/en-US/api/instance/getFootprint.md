# getFootprint(data)
`getFootprint` get one bar's footprint data, as `setFootprintResolver` returns it.

## Reference {#reference}
<!--@include: @/@views/api/references/instance/getFootprint.md-->

### Parameters {#parameters}
- `data` The bar.

### Returns {#returns}
`getFootprint` returns the footprint data or `null` .
