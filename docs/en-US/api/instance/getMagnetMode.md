# getMagnetMode()
`getMagnetMode` get how strongly the crosshair snaps to the bars.

## Reference {#reference}
<!--@include: @/@views/api/references/instance/getMagnetMode.md-->

### Parameters {#parameters}
`getMagnetMode` does not accept any parameters.

### Returns {#returns}
`getMagnetMode` returns `'normal'`, `'weak'` or `'strong'` .
